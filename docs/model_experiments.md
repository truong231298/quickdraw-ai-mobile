# Model Experiments

| Model | Accuracy | Params |
|---|---|---|
| CNN | 91.2% | 1.2M |
| ResNet18 | 95.8% | 11M |
| MobileNetV3 | 95.1% | 2.5M |

## Observations

- MobileNetV3 provides the best tradeoff between speed and accuracy.
- ResNet18 achieves highest accuracy but increases inference latency.
